FOR BROWSER AGENTS

Operate the target browser through this page

  1. Select a target tab, then choose Observe target.
  2. Read the screenshot, page text, and numbered element list together.
  3. Use a listed element ref for Click, Fill, or Select. Observe again to verify.
  4. Full Access runs actions immediately. Safe mode can still require one-time approval in the extension popup.

Boundary: this works only when your browser tool runs on this computer and can open loopback URLs. A cloud-hosted browser cannot reach this machine's localhost.

NATIVE COMPUTER

Background window sessions

Start Local Computer Helper to enable desktop control.

Non-interruption contract: every action is bound to one exact background window. The helper never uses global HID input, moves the hardware cursor, activates the target app, or silently falls back to foreground control. Unsupported delivery fails closed.

Connect the helper, choose a window, then observe it. Click the captured window to select coordinates.
